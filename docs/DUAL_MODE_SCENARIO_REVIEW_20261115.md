# 全自动流程与循环风险复核

2026-11-15（Asia/Taipei）。待审核设计推演；未实现外围、未启动浏览器、未进行产品测试。

## 1. 两种进度及本轮终态

平台进度保留首页原值。外围执行结果来自本轮已校验身份、完整目录和任务结果的内层上报；不根据首页未满推断必须重新学习，也不推断未满必然由作业导致。已识别作业可以显示其类别，原因不明时只显示平台总体进度未满。

每门课程在本轮有待处理、运行中、完成、略过、失败待处理五种简单状态。恢复是运行中的阶段，不另起第二个课程执行器。后面三种为本轮终态，不被再次扫描首页推翻。

- 完成：内层确认全部受支持任务满足现有完成机制，未确认数为零；必要的课末核对已结束。
- 略过：首页可靠100%，或当前完整目录明确只有非处理资源；保存不同原因。
- 失败待处理：有未确认任务，有限恢复已结束；不称为完成。
- 暂停是整轮状态；当前课程仍保留未完/未知，不能为了结束队列改写完成。

本轮停止条件：初次列表扫描已确认完成，所有课程均有终态，没有仍在运行的执行器、待发送选课或未完成交接。存在失败时显示本轮结束并列出待处理项；无失败时显示本轮可自动处理的学习任务已完成，作业考试未处理。不能显示平台所有课程100%。

完整目录与当前确认是前提：空白加载页不等于无任务，文档标记未知不等于参考资料，点过或达到切换比例不自动等于平台确认。继续复用内层判断。

## 2. 八门课程按顺序推演

下列数据是假设案例，不是用户真实课程记录。

| 顺序 | 进入前/课内情况 | 内层与外围行为 | 本轮终态 |
|---|---|---|---|
| A | 首页100%且信息可靠 | 不进入，记录首页依据 | 略过：首页已满 |
| B | 首页80%；视频音频及必做文档全部确认，只剩作业 | 进入扫描后记录内层完成，首页仍80%也不重入 | 完成 |
| C | 首页40%；两段视频和一份必做文档未完成 | 原短时优先、原目标、文档观察、末轮核对；最终内层确认全部 | 完成 |
| D | 首页0%；完整目录只有作业和考试 | 内层确认没有受支持任务，不进入播放 | 略过：无可处理任务 |
| E | 首页60%；内层恢复失败 | 确认停止，先保存外围额度，再退出列表重进一次；实际推进且最终确认 | 完成，重进1次 |
| F | 首页30%；首次及重进均失败 | 确认停止，保留失败证据，继续G | 失败待处理，重进1次 |
| G | 首页70%；文档预览失败但稍后目录完整完成标记出现 | 内层按目录标记确认，不把预览失败单独当成任务失败 | 完成 |
| H | 首页未知；实际音视频和文档已确认 | 进入完整核实，以内层有效结果结束 | 完成 |

结束汇总：8门已处理，5门内层确认完成、2门略过、1门失败待处理；停止本轮。B、D、F的首页可以仍不足100%，不会回到它们再循环。不能把F写成完成。

## 3. 故障注入推演

| 意外 | 判定与动作 | 防止的问题 |
|---|---|---|
| 首页百分比滞后 | 已有本轮内层有效终态就保留；不循环刷新首页等100% | 作业/延迟导致反复进课 |
| 必做文档一直空心或半圆 | 继续内层原有限确认；未确认则局部失败，外围最多重进一次 | 点击成功冒充完成 |
| 目录漏章、加载空白、未知文档标记 | 不出成功结果；沿原内层恢复，结束失败后进入外围故障路径 | 将未知当不支持而漏学 |
| 没有文档但音视频完整可判 | 正常依据媒体结果，不等待并不存在的文档 | 零文档死等 |
| 无课程或空目录 | 只有可信“无课程/无任务”证据才结束；加载失败不报100% | 空数组假成功 |
| 内层仍在正常播放长视频 | 外围等待；复用实际进展和内层停滞检测，不加整课播放时限 | 长视频被错误重进 |
| 播放停滞但消息轮询正常 | 普通轮询/重复日志不算进展；内层原停滞恢复先处理 | 活跃标志掩盖停滞 |
| 课末通知丢失 | 从后台本轮本课本尝试最新结果对账；有效终态只消费一次 | 重播或无限等通知 |
| 脚本失联、页面冻结 | 有界核对后暂停外围；不能确认停止就不导航和换课 | 双执行器及静默死等 |
| 页面接回迟迟失败 | 外围交接阶段预算到期后失败或暂停；同阶段重试不重置期限 | 旧导航重试无限延长 |
| 重进前后用户暂停 | 撤销待派发操作；已用额度保留，等待用户继续 | 迟到启动及重进次数重置 |
| 浏览器关闭、重启、休眠 | 恢复检查点后先待确认；不得自动重开课程或直接判失败 | 旧授权复活、睡眠误判 |
| 作业页或登录验证码出现 | 使用明确内层分类；全局登录验证暂停，不连续刷其它课程 | 把全局阻断当单课故障 |
| 重复或旧课程消息 | 校验本轮/课程/尝试/代数；已消费终态不再次消费 | 双重选课和错误完成 |
| 课程卡片重新排序、同名、消失 | 依原身份核对重新定位，禁止只按旧索引点击；无法唯一核实时暂停 | 选错课 |
| 已完成课程再次出现在课表 | 保留本轮终态；运行中更新不重建队列 | 首页刷新重新入队 |
| 中途新增课程/资源 | 队列不自动扩大；活动课程发现目录变化由内层核实，不确定则失败/暂停；本轮完成结论注明观察时点 | 无穷追加范围和过期结果 |
| 关键状态保存失败 | 暂停；在重进额度持久化成功前不执行重进 | 刷新后无限恢复 |
| 纯诊断归档失败或裁剪 | 提示记录降级；不删除课程终态/额度，不以日志缺失重新执行 | 日志容量改变任务行为 |

## 4. 必须落到实施和验收的约束

1. 固定本轮扫描范围和唯一课程身份；不直接使用首页百分比生成每一次待办列表。
2. 保存每课本轮终态，与首页进度、内层临时运行状态分别表示；终态本轮不可自动退回待办。
3. 每课正常外围派发一次、额外外围重进至多一次。内层原有资源重试与刷新独立但仍沿用其有限规则；不能因重启内层清空外围额度。
4. 外围导航/返回/重进/接回每阶段建议180秒总预算，复用原短超时，重复事件不续期；不限制正常媒体总时长，不新增资源点击循环。
5. 停止无法确认、账号验证、持久化失败等转为明确暂停；暂停不等于完成，不偷偷跳课。
6. 列表走完即汇总停止，不自动重建下一轮；用户明确新一轮才重新扫描，历史结果仅作参考。这样新作业/资源也有后续重新核实入口，不永久跳过旧课程。

这能排除设计层面因作业未完成而造成的循环，并给主要异常设置出口；不能据此声称实现已经通过测试，也不能保证任意外部故障下全部课程都能完成。
