# 1.3.9 单课内核测试版

日期：2026-11-13（Asia/Taipei）。开发目录为本仓库根目录，从当前1.3.8工作区剥离外层自动跨课功能，版本标为1.3.9以便区分安装结果。本次不是最终架构重写。

## 本轮边界

- 删除界面的「一键学习全部课程」、相应点击处理和前台自动挑选下一门课程的调度。
- 后台拒绝旧 `workflow: auto` 启动与继续命令，移除按课表100%跳过课程、故障后跳下一门、学习页关闭后自动重进以及自动跨课交接。
- 旧全自动或旧多课队列从session和磁盘读取时停止，清除导航及继续授权，保留目录、资源记录、日志和原中断诊断。读取迁移只执行一次。
- 保留获取列表、用户选课、同一门课扫描后学习、课内资源顺序、80%–100%目标、文档访问、课末刷新复核、暂停继续及有界恢复。
- 本课完成或仍有未确认项目，都会停下等待用户选择；不会自动进入下一门。
- 仅保留旧单课兼容协议，不包含旧跨课队列。旧内层执行分支本轮未统一重写；公开界面继续使用现有单遍执行器。

后续新的外层控制应在单课流程验收后再设计。单课内的目录识别、章节切换、平台报错等既有问题仍需实测，本次剥离不等于已解决这些问题。

## 用户测试步骤

本轮只修改代码并运行本地合成测试，没有操作现有浏览器或启动真实课程。

1. 在Edge扩展管理页重新加载原目录的扩展，核对显示 **1.3.9 单课内核测试版（基于1.3.8）**；重新加载网站页面以更新已注入的页面脚本。
2. 展开助手，点击「获取课程列表」。确认列表出现后停止，没有「一键学习全部课程」，也没有自动打开任何课程。
3. 只点一门测试课的「开始学习」。确认先完整扫描该课，随后仅处理本课资源；其他课程不被打开。
4. 测试「暂停→继续」；手动刷新页面后确认需要显式继续。查看开始播放后实际时间推进，不能仅以日志中的started判定成功。
5. 本课首轮后允许既有统一复核流程完成；检查平台完成标记、未确认项及失败记录。最终应停下等待用户选择，学习页保留。
6. 若出现平台弹窗、错选资源或意外导航，先暂停并保留当前课程、资源、最近日志和播放状态。不要把所有异常统一认定为平台故障。
