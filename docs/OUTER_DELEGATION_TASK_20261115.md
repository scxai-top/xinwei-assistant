## 实现重点

1. 本轮列表固定，首页可靠100%略过，其余按列表顺序进入；课程身份不能只用可变索引。未知明细不填0。
2. 内层完整有效结果是自动任务完成依据。只剩已识别作业/考试时结束本课；首页仍未满不重新入队；未知必做文档等不得忽略。
3. 外围结果同轮持久化，结果日志与最新状态同源，不解析中文日志。结果/额度独立于可裁剪诊断。旧消息、重复结果、刷新不得倒退课程终态或二次派发。
4. 内层运行/恢复时外围等待；明确局部失败且执行器已停止才退出列表重进同课一次。先保存额度再导航，不能仅重新调用缓存learnUrl冒充返回列表。
5. 重进仍失败保留待处理，安全切下一门；整轮不补跑。暂停/验证码/关键存储错误/无法确认停止时整体暂停，不标完成。
6. 外围导航和交接阶段有不因重试续期的总预算，建议180秒；仅在外层授权时生效，不能改变半自动或内层原恢复机制。长视频不受该预算限制。复用现有同步、消息、串行取消和检查点，不新增第二个资源监督循环。
7. 对实际实现难点先分析原符号和调用链，保持简单、小体积、无新增运行依赖或权限。遵守计划的日志容量和字节上限。
